Tujuan project: mengganti pencatatan Excel manual dengan aplikasi input tervalidasi yang langsung menampilkan yield dan NG rate per stasiun, model, dan supplier. Data adalah simulasi.

Pertanyaan
Bagaimana mengganti pencatatan Excel manual dengan aplikasi input yang tervalidasi dan langsung menampilkan yield dan NG rate per stasiun, model, dan supplier?
Data
Simulasi: Excel lama 30.125 baris (750 bermasalah, 2,5%), data aplikasi 30.000 tray, 1.453.218 unit, 10 stasiun, 4 supplier.
Temuan utama
Validasi menangkap 750 dari 750 error Excel lama; aplikasi menyimpan 0 baris yang melanggar aturan dan mencegat 14,8 isian salah per 1.000. Reflow Soldering stasiun terburuk (NG rate 4,06%).
Keputusan yang didukung
Fokus perbaikan di Reflow Soldering dan Functional Test; periksa Supplier C di Functional Test; beri pendampingan 2 minggu untuk operator baru. Hemat sekitar 62,4–78,0 jam rekap per tahun perkiraan.
Metode
Aplikasi Streamlit + SQLite/PostgreSQL dengan aturan validasi, view KPI yang sama untuk semua halaman, pytest, cek silang pandas dan Excel (LibreOffice), pemindaian kredensial (gitleaks).
Catatan jujur
Validasi tidak menangkap angka yang keliru tetapi masuk akal (3,0 per 1.000 tray masih dikoreksi lewat fitur edit). Analisis deskriptif; uji statistik formal ada di Project 29.

  • Cek silang view SQL vs pandas: 4.678 dari 4.678 pemeriksaan; vs Excel (LibreOffice): 17 dari 17 cocok.
  • Fakta tertanam: 5 dari 5 sesuai; enam jenis error Excel lama tertangkap tepat oleh aturannya (750 dari 750).
