Project 15: kapan proses keluar kendali? (simulasi)

Tujuan project: memantau kekuatan ikatan glue lensa lampu dari force push test dengan grafik kendali dan alert otomatis. Data adalah simulasi.

Status: analisis selesai, finalisasi belumManufaktur · SPCDATA SIMULASIPython · SQL · Streamlit
DATA SIMULASI. 600 run push test dibangkitkan dengan 3 gangguan proses yang sengaja ditanam. Hasil membuktikan metode bekerja pada gangguan itu, bukan kondisi pabrik nyata.
Status: analisis dan dashboard selesai, finalisasi belum. Rekomendasi akhir, aturan alert final, dan perhitungan dampak belum dikerjakan.

RingkasanDibaca 1 menit

Pertanyaan
Kapan proses perekatan lensa lampu keluar kendali atau Cpk turun di bawah 1,33, dan apakah sinyalnya terlihat sebelum banyak hasil uji NG?
Data
Simulasi: 592 run push test (satu file per run), 4 aliran (2 model × 2 kondisi), 592 run dipakai.
Temuan utama
Grafik X-bar dan R mendeteksi ketiga gangguan yang ditanam: drift Model B sesudah oven (alert pertama 26 Mei, di run pertama jendela), gangguan mendadak Model A sebelum oven, dan sebaran membesar di mesin PT-02 (terdeteksi di 4 dari 4 aliran).
Keputusan yang didukung
Pakai aturan X-bar + R dengan limit dari baseline 14 hari; false alarm di luar jendela gangguan 2,3% run untuk X-bar dan 0,5% untuk R.
Metode
Python (pandas, SciPy), DuckDB + SQL, grafik kendali X-bar/R, aturan Western Electric, Cpk dengan CI, simulasi Monte Carlo ARL, dashboard Streamlit.
Catatan jujur
Gangguan Model A sebelum oven hanya 2 run di jendela, terlalu sedikit untuk kesimpulan kuat. Hasil bergantung pada pilihan baseline (lihat grafik 4).

Model B sesudah oven: alert X-bar pertama 26 Mei di run pertama jendela; 52 dari 52 run di jendela memicu alert.

Temuan 2 · Capability

Baseline sehat, Cpk di atas 1,33

Cpk baseline 1,98 sampai 2,63 di semua aliran; sesudah oven 1.366 g lebih tinggi pada Model A.

Temuan 3 · Kecepatan

Pergeseran besar cepat tertangkap

Rata-rata 10,8 run untuk pergeseran 1σ, 3,3 untuk 2σ, 1,6 untuk 3σ (Monte Carlo, 2.000 replikasi).

Rekomendasi dan dampakBelum final

  • Gunakan X-bar dan R dengan baseline bersih 14 hari sebagai aturan alert awal.
  • Periksa mesin PT-02 bila alert R muncul di banyak aliran sekaligus (tanda sebaran mesin, bukan model).
  • Tinjau Cpk bergulir berdampingan dengan grafik kendali.
Dampak (NG terhindari) belum dihitung. Angka dampak akan diberi label perkiraan setelah aturan alert final.
