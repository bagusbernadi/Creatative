Project 26: bisakah batas spec di PDF dibaca otomatis dan dicocokkan dengan hasil ukur? (simulasi)

Tujuan project: membaca batas spesifikasi dari PDF datasheet menjadi tabel, mencocokkannya dengan hasil ukur, dan menemukan parameter yang paling sering gagal. Data adalah simulasi; LLM belum dijalankan.

Status: selesai (dashboard belum di-deploy)Manufaktur · ekstraksi dokumenDATA SIMULASIPython · SQL · DuckDB
DATA SIMULASI, TANPA LLM. 24 PDF datasheet dan hasil ukur dibangkitkan. Langkah LLM ada di kode tetapi belum dijalankan (tidak ada API key); ekstraksi memakai aturan (regex). Akurasi 100% pada aturan lengkap dihitung pada gold set kecil yang disusun orang yang sama; jangan diekstrapolasi.

RingkasanDibaca 1 menit

Pertanyaan
Bisakah batas spesifikasi di PDF datasheet dibaca otomatis, dicocokkan dengan hasil ukur produksi, dan dipakai mencari parameter yang paling sering gagal atau paling dekat ke batas?
Data
Simulasi: 24 PDF datasheet LED (3 model × 3 revisi, 5 format, 1 hasil scan), 108.540 baris hasil ukur mentah dari 18.000 unit; 2.700 baris (2,49%) kotor, semuanya ditemukan.
Temuan utama
Ekstraksi aturan dasar hanya 46,9%, aturan lengkap 100,0% (gold set 160 field). 98,59% unit lolos; cri 12W penyumbang gagal terbesar (93 dari 255 kegagalan, 36%).
Keputusan yang didukung
Nilai hasil uji dengan revisi spec yang berlaku pada tanggal uji; pantau cri 12W lebih dulu. Pengecekan manual sekitar 16 jam per tahun perkiraan.
Metode
Ekstraksi PDF (aturan dasar vs lengkap, validasi skema, antrean review), DuckDB + SQL (ASOF join revisi), Wilson CI, chi-square dengan Holm, Cochran-Armitage, cek silang pandas dan Excel (LibreOffice).
Catatan jujur
LLM tidak dijalankan. Gold set kecil dan disusun orang yang sama dengan aturan, jadi 100% optimistis. 1 PDF hasil scan masuk antrean review (tanpa OCR).

Revisi usang menyembunyikan kegagalan

Dengan Rev 1.0, 54 dari 254 unit gagal (21,3%) tampak lolos; dengan Rev 2.0 hanya 3.

Temuan 3 · Margin

cri 12W paling dekat ke batas

12,3% hasil cri 12W lolos dengan margin < 1 simpangan baku. Model berbeda signifikan (Holm) pada cri, power_factor, luminous_flux.
