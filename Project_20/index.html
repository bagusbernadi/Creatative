Project 20: bisakah CSV mesin push test masuk database otomatis? (simulasi)

Tujuan project: mengganti macro VBA dan copy-paste manual dengan pipeline yang memuat CSV push test ke database dan menghitung Cpk per model dan kondisi. Data adalah simulasi.

Status: selesai (dashboard belum di-deploy)Manufaktur · pipelineDATA SIMULASIPython · DuckDB · SQL
DATA SIMULASI. Ribuan CSV mesin push test dibangkitkan dengan masalah yang ditanam (format baru, file rusak, salinan). Macro VBA lama ditiru dari deskripsi, bukan dari workbook asli.

Pertanyaan
Bagaimana mengganti macro VBA dan copy-paste manual agar CSV mesin push test masuk database otomatis, terbaca benar, dan siap dianalisis per model dan kondisi?
Data
Simulasi: 1.500 file unik (+14 salinan), 18.003 hasil ukur dimuat, 2 mesin, 2 model, sebelum dan sesudah oven.
Temuan utama
1.440 dari 1.500 file (96,0%) dimuat; 60 masuk karantina dengan alasan. Satu dari 4 kombinasi di bawah Cpk 1,33: Model B before oven (1,04). Macro lama salah membaca 424 nilai (3,1%).
Keputusan yang didukung
Jalankan pipeline terjadwal dan tinjau karantina; selidiki kalibrasi PT-02; turunkan variasi kombinasi Cpk rendah. Hemat sekitar 481 jam kerja manual per tahun perkiraan.
Metode
Parser Python + hash isi + karantina, DuckDB dan view SQL, Cpk dengan CI, uji permutasi untuk penurunan rata-rata, cek silang pandas dan Excel (LibreOffice).
Catatan jujur
Generator dan pipeline ditulis orang yang sama, jadi uji pemulihan optimistis. 3 dari 23 file terpotong tidak terdeteksi sebagai terpotong.
